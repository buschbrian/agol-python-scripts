# Delivery reference files

Authoritative documents for the source acquisition, kept here so every number in
[RECORD.md](../RECORD.md) can be checked without finding the original
delivery. These are public USGS/Aero-Graphics products: the metadata states that no restrictions
apply to the data. Nothing here is generated by this toolbox, and nothing here should be edited.

| Path | What it is |
|---|---|
| `metadata/Salt_Lake_Valley_ClassifiedPointCloud_Metadata.xml` | FGDC metadata for the point cloud: pulse spacing, delivered classes, flag policy, accuracy |
| `metadata/Salt_Lake_Valley_DEM_Metadata.xml` | FGDC metadata for the hydro-flattened bare-earth DEM |
| `metadata/Salt_Lake_Valley_Breakline_Metadata.xml` | FGDC metadata for the breaklines |
| `reports/USGS_UT_2023SaltLakeCo_C24_Project_Report.pdf` | USGS project report; the accepted vertical-accuracy results and work-unit details |
| `reports/USGS_UT_2023_SaltLakeCo_1_C24_LMR.pdf` | Aero-Graphics mapping report; flight parameters, processing steps, documented voids, measured density |
| `index/Salt_Lake_Valley_QL1_TI.*` | Official 1363-tile index; the naming schema the delivery tiles follow |
| `index/Salt_Lake_Valley_QL1_DPA.*` | QL1 data product area, about 493 mi² |
| `index/Salt_Lake_Valley_Lidar_Swath_Index.*` | 79 dated swaths; the source of per-tile flight dates |

Pass the swath index to the delivery indexer to stamp flight dates onto tile bounds:

~~~powershell
& $proPython -m canopy index-delivery 'G:\GIS\2024 Lidar for tower extract' scratch\delivery_index `
    --swaths acquisitions\2023-salt-lake-valley\reference\index\Salt_Lake_Valley_Lidar_Swath_Index.shp
~~~

## Not kept here

Two files from the same delivery are deliberately left out because nothing reads them and each is
larger than everything above combined:

- `APPENDIX C_GPS_PROCESSING_REPORT_SLV_LIDAR.pdf` (40 MB) — GPS trajectory processing detail.
- `UT_2023_SaltLakeCo_1_C24_Breaklines.gpkg` (37 MB) — delivery breaklines.

They arrived in `SLCo_Utah_2023_Reports.zip` and `SLCo_Utah_2023_shps.zip`. The full delivery also
contains `low_confidence_areas.shp`, which delineates the smoke-plume ground voids and is worth
requesting; it was not in the local copy.
